# Omniverse Storage Thumbnail API Docs

Documentation for the public Thumbnail API specification (REST and gRPC). The pages are Markdown sources under
[`docs/`](docs/) and read as-is. NVIDIA builds the rendered site from them internally; in NVIDIA's source repository,
where the build tooling lives, `./repo.sh docs` builds it.

[Read the docs](http://omniverse-docs.s3-website-us-east-1.amazonaws.com/thumbnail-api/latest/index.html)
