# Omniverse Storage Thumbnail Service Docs

Documentation for operating the Thumbnail Service reference implementation. The pages are Markdown sources under
[`docs/`](docs/) and read as-is. NVIDIA builds the rendered site and the PDF edition from them internally; in NVIDIA's
source repository, where the build tooling lives, `./repo.sh docs` builds the site and `./build_pdf.sh` the PDF.

[Read the docs](http://omniverse-docs.s3-website-us-east-1.amazonaws.com/thumbnail-service/latest/index.html)
