# Security Policy

If you believe you have found a security vulnerability in any of the content services, APIs or libraries in this repository, please report it privately.

Send a detailed report to **psirt@nvidia.com** ([PSIRT — NVIDIA Product Security Incident Response Team](https://www.nvidia.com/en-us/security/)). Include:

- the affected service or library, and its version or commit;
- a description of the vulnerability and its potential impact;
- steps to reproduce, including relevant configuration or deployment details;
- any relevant logs, stack traces, or proof-of-concept material.

Please do not open GitHub issues or pull requests for suspected security vulnerabilities. NVIDIA PSIRT will acknowledge your report and coordinate disclosure and remediation timelines directly with you.

Some components also carry their own `SECURITY.md`, for example `permissions/reference/permission-service` and `storage/api`. This policy applies to the whole repository.
