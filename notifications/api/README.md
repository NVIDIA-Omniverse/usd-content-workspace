# notification-protos
The protobuf API definitions for the Omniverse notification services.

| Service | Package | File |
| --- | --- | --- |
| `EventPublishingService` | `nvidia.omniverse.notifications.publisher.v1beta` | `protos/nvidia/omniverse/notifications/publisher/v1beta/event_publisher.proto` |
| `EventConsumerService` | `nvidia.omniverse.notifications.consumer.v1beta` | `protos/nvidia/omniverse/notifications/consumer/v1beta/event_consumer.proto` |

`protos/` is a Buf module (`buf.yaml`, `buf.lock`).
